CMYK 换算

K = 1 − max(R′, G′, B′)
C = (1 − R′ − K) / (1 − K)
M = (1 − G′ − K) / (1 − K)
Y = (1 − B′ − K) / (1 − K)

R′、G′、B′ 为归一化到 0-1 的通道值；K = 1 时 C = M = Y = 0。

1. 导入图像上传或选择示例
2. 连续放大滚轮或滑块
3. 观察像素方块网格与高亮
4. 读取像素值RGB · CMYK
