当前步骤解释

亮度恒定 / Brightness Constancy \(I(x,y,t) \approx I(x+u,y+v,t+1)\) 同一个物理点在相邻帧中亮度近似不变。
光流约束 / Flow Constraint \(I_xu + I_yv + I_t = 0\) \(0.00u + 0.00v + 0.00 = 0\)
孔径问题 / Aperture Problem \(1\ \text{equation},\ 2\ \text{unknowns}\) 单像素只能给出一条 u-v 约束线，需要局部窗口补充更多方程。
光流估计分类
稀疏光流选择角点、纹理点等少量可跟踪特征进行估计。
稠密光流对图像中尽量多的像素估计二维运动向量。
一阶近似
\[ \begin{aligned} I(x+\Delta x,y+\Delta y,t+\Delta t) &\approx I + I_x\Delta x + I_y\Delta y + I_t\Delta t\\ 0 &= I_x\Delta x + I_y\Delta y + I_t\Delta t\\ \Delta t=1 &\Rightarrow I_xu + I_yv = -I_t \end{aligned} \]
