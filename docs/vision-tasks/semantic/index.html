IoU 交互评测
Metrics Lab

拖动下方滑块控制预测区域 (Prediction) 与真实标注 (Ground Truth) 的重合程度，直观了解分割评价算法的数学推断过程：

GT 真实
Pred 预测
Overlap
相交距离偏移量 50%
交集部分 (Intersection) 50 px²
并集部分 (Union) 150 px²
数学计算公式
$IoU = \frac{|GT \cap Pred|}{|GT \cup Pred|} = \frac{50}{150} \approx 0.333$
