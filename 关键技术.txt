卷积相关系统技术说明

摘要

本系统围绕计算机视觉中的卷积操作设计，实现了卷积计算过程可视化、参数调节、多通道与多卷积核展示、特殊卷积演示、真实图像卷积应用和 CNN 手写数字识别等功能。

后端通过 NumPy 完成矩阵卷积、图像卷积和手写 CNN 推理。卷积可视化部分支持 7×7 输入矩阵与 3×3/5×5 等卷积核的计算演示，并可调节 stride、padding、dilation、输入通道数和卷积核数量。系统通过高亮卷积窗口、展示输入 Patch、卷积核、逐元素乘积矩阵和求和结果，直观呈现每个输出值的计算过程。

在特殊卷积部分，系统展示了 1×1 卷积、空洞卷积和蛇形卷积。其中，1×1 卷积用于多通道信息融合；空洞卷积通过 dilation 扩大感受野；蛇形卷积通过路径采样展示对细长弯曲结构的特征提取思想。系统还进一步调研并可视化了 Pointwise Convolution、ASPP 和 DSConv 等相关结构，说明这些卷积在真实视觉模型中的应用。

此外，系统支持将卷积核应用于真实图像，实现模糊、锐化、边缘检测和 Sobel 算子效果展示。最后，系统接入了使用 NumPy 手写 CNN 训练得到的手写数字识别模型，后端加载已保存参数文件，对 canvas 手写输入进行预处理并完成 0～9 数字分类。

整体上，本系统从卷积底层计算、参数机制、特殊卷积形式到 CNN 模型应用，较完整地展示了卷积在计算机视觉中的核心作用。

一、系统概述

本系统围绕“卷积”进行设计，实现了卷积计算过程可视化、卷积参数交互调节、多通道与多卷积核展示、特殊卷积演示、真实图像卷积应用、进阶卷积结构调研以及卷积模型应用等功能。

后端卷积矩阵计算、图像卷积处理和 CNN 模型推理主要使用 NumPy 实现（模型复用前期机器学习课程）。

二、卷积计算过程可视化

系统首先实现了标准二维卷积的计算过程可视化。可以随机生成输入矩阵和卷积核，系统默认使用 7×7 输入矩阵与 3×3 卷积核进行演示。

在计算过程中，系统会高亮当前卷积核覆盖的输入窗口，并将该窗口单独展示在“当前卷积计算画布”中。计算画布中依次展示：

输入窗口 Patch × 卷积核 Kernel → 逐元素乘积 Product → 求和 Sum → 写入输出特征图 Feature Map

相比只给出最终输出结果，这种方式能够更直观地展示每一个输出值的来源，使用户能够看到卷积计算中“局部区域提取、逐元素相乘、累加求和”的完整过程。

三、卷积参数调节与输出尺寸计算

系统提供了可交互的卷积参数面板，支持用户修改卷积核大小、步长 stride、填充 padding、空洞率 dilation、输入通道数和卷积核数量。

系统根据当前参数实时计算输出特征图尺寸，核心公式为：

effectiveK = dilation × (K - 1) + 1

outH = floor((H + 2P - effectiveK) / S) + 1
outW = floor((W + 2P - effectiveK) / S) + 1

其中，K 表示卷积核大小，P 表示 padding，S 表示 stride，dilation 表示空洞率，effectiveK 表示考虑空洞采样后的有效卷积核大小。

通过该模块可以观察到：
1. 卷积核越大，单次覆盖区域越大，输出尺寸通常越小；
2. padding 可以在输入边界补零，从而改变输出尺寸；
3. stride 控制卷积核滑动步长，stride 越大，输出尺寸越小；
4. dilation 可以扩大有效感受野，而不增加卷积核参数数量。

四、多通道卷积与多卷积核机制

系统支持多通道输入和多卷积核输出。

在多通道输入情况下，例如输入通道数为 3，系统会显示三个输入矩阵。一个卷积核内部会包含与输入通道数相同数量的通道。每个输入通道分别与对应的卷积核通道做卷积计算，得到各自的和，最后将所有通道的和相加，得到当前输出位置的最终值。

该部分重点体现了 CNN 中多通道卷积的基本机制：

输入通道数决定每个卷积核内部有多少个通道切片；
卷积核数量决定最终输出多少个矩阵。

例如：
1. 输入通道数为 3，卷积核数量为 1，则输出 1 个矩阵；
2. 输入通道数为 3，卷积核数量为 3，则输出 3 个矩阵。

五、当前卷积计算画布与动态演示

为了让卷积过程更加直观，系统设计了“当前卷积计算画布”。该区域将当前参与计算的输入窗口、卷积核切片、逐元素乘积矩阵和求和结果单独放大展示。

系统支持单步计算和自动播放两种方式：
1. 单步计算：每点击一次计算一个输出位置；
2. 自动播放：系统按照卷积核滑动顺序自动演示完整计算过程。

在演示过程中，当前输入窗口、当前卷积核、当前乘积项和输出特征图中的当前位置会同步高亮，帮助用户理解输入矩阵、卷积核和输出特征图之间的对应关系。

六、1×1 卷积可视化

系统实现了 1×1 卷积的展示。1×1 卷积不会扩大空间感受野，它只作用于同一空间位置，因此在单通道情况下作用较简单；但在多通道输入中，1×1 卷积可以对同一位置的不同通道进行加权求和，实现通道融合。

系统通过多通道输入示例展示 1×1 卷积的计算过程：

Output = C1 × w1 + C2 × w2 + C3 × w3

该模块用于说明 1×1 卷积常用于通道融合、通道压缩、通道升维和减少模型参数量。在进阶调研中，系统进一步将 1×1 卷积联系到 MobileNet 中的 Pointwise Convolution，用于说明其在轻量化网络中的作用。

七、空洞卷积与 ASPP 多尺度结构

系统实现了空洞卷积可视化。空洞卷积通过 dilation 参数控制卷积核采样点之间的间隔，使卷积核在参数量不变的情况下获得更大的有效感受野。

例如，3×3 卷积核在 dilation=2 时，有效感受野变为 5×5；在 dilation=3 时，有效感受野变为 7×7。系统会高亮实际参与计算的采样点，并淡化被跳过的位置，从而展示空洞卷积的稀疏采样特点。

在进阶调研部分，系统进一步展示了 ASPP（Atrous Spatial Pyramid Pooling）多尺度空洞卷积结构。ASPP 通过多个不同 dilation rate 的并行分支提取不同尺度的上下文信息，然后将多个分支结果 concat 拼接，并通过 1×1 卷积进行融合。该模块用于说明空洞卷积在语义分割等任务中的多尺度上下文建模作用。

八、蛇形卷积与动态蛇形采样

系统实现了蛇形卷积。该模块并不是简单改变卷积计算顺序，而是通过蛇形路径采样的方式，展示卷积可以沿连续路径提取特征。

普通卷积使用规则方形窗口采样，而蛇形卷积更强调沿细长、弯曲路径采样。该思想适合用来理解道路、血管、裂缝等连续结构的特征提取。

在进阶调研中，系统进一步引入 DSConv / DSCNet 的示意，对比了三种采样方式：
1. 标准卷积：规则 K×K 方形采样；
2. 固定蛇形卷积：沿预设蛇形路径采样；
3. 动态蛇形卷积：路径根据输入中的细长结构进行调整。

系统特别说明，该模块是动态蛇形路径示意，并非完整论文级模型复现，主要用于帮助理解动态路径采样的基本思想。

九、真实图像卷积应用

为了将矩阵卷积与真实图像处理联系起来，系统实现了图像卷积应用模块。用户可以上传图片，并选择不同的经典卷积核进行处理，包括：
1. 均值模糊卷积核；
2. 锐化卷积核；
3. 边缘检测卷积核；
4. Sobel X；
5. Sobel Y；
6. 自定义卷积核。

系统会将当前卷积核应用于图像，并展示处理结果。通过该模块可以直观看到不同卷积核在图像平滑、细节增强、边缘检测和方向梯度提取中的作用。

十、卷积模型应用：在线手写数字识别

系统最后接入了一个使用 NumPy 手写实现并训练得到的 CNN 手写数字识别模型。该模块展示了卷积从底层计算到实际模型应用的过程。

用户可以在网页 canvas 中书写 0 到 9 的数字，前端将画布图像发送给 Flask 后端。后端完成以下预处理步骤：
1. base64 图像解码；
2. 转灰度；
3. 根据背景和前景判断是否反色，使其接近 MNIST 黑底白字格式；
4. 裁剪数字有效区域；
5. 保持比例缩放；
6. 居中填充到 28×28；
7. 归一化到 0~1；
8. reshape 为 NumPy CNN 所需的 NCHW 格式，即 (1, 1, 28, 28)。

后端随后加载已经训练好的 NumPy CNN 参数文件进行推理，并返回预测数字、置信度和 0~9 的概率分布。

该 CNN 模型包含两个卷积块和一个分类头，基本结构为：

Input 1×28×28
→ ConvLayer 1
→ ReLU
→ MaxPooling
→ ConvLayer 2
→ ReLU
→ MaxPooling
→ FullyConnected
→ ReLU
→ FullyConnected
→ Softmax 0~9

其中，卷积层负责提取笔画、边缘和局部形状特征；池化层用于压缩空间尺寸；全连接层和 Softmax 用于输出最终数字类别概率。

十一、NumPy CNN 参数保存与后端推理

为了实现在线识别，系统将训练和推理分离。训练脚本负责训练模型并保存参数文件，后端推理模块只负责加载已经训练好的参数并进行前向推理。

训练完成后，模型参数被保存为 npz 文件，主要包括卷积层和全连接层的 weights 与 bias。Flask 后端启动后或首次请求时会构建与训练时一致的 CNN 结构，并加载该参数文件。这样避免了在网页端重新训练模型，提高了系统运行效率。

十二、总结

本系统围绕卷积展开，从基础卷积计算过程出发，依次展示了卷积参数影响、多通道卷积、多卷积核机制、1×1 卷积、空洞卷积、蛇形卷积、真实图像卷积应用和 CNN 手写数字识别应用。

系统不仅展示了卷积计算结果，更重点展示了卷积的计算过程、参数机制、特殊卷积设计动机以及卷积模型在实际识别任务中的应用。通过该系统，可以较完整地理解卷积从底层矩阵运算到计算机视觉模型应用的整个过程。
