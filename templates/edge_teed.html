    当前过程

    TEED / HED 是深度边缘检测拓展展示。Sobel / Canny 仍然是本实验核心手写算法。

    FORMULA / 公式
    F_i = Conv_i(F_{i-1})
    Fi Convi Fi-1 S1 S2 S3 w1 w2 w3 sum sigmoid Final
    SIDE OUTPUT / 侧输出说明

    Side Output 从不同深度的特征层直接产生边缘预测。浅层更关注纹理和细节，深层更关注整体轮廓。

    FUSION / 融合说明

    Fusion 将多个 side output 融合，得到最终边缘预测图。模型文件缺失时这里只展示结构和占位，不伪装成真实推理结果。

    CODE BOUNDARY / 代码边界

    TEED 为公开预训练轻量模型的拓展展示，不属于 Sobel、Canny、NMS、Hysteresis 等手写核心算法范围。
