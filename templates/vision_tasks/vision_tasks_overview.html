TASK TAXONOMY

任务谱系

从整体判断逐步细化到实例级空间理解

  1. Image-level图像级分类

    输出：class probability

    p(y|image) ∈ RC
  2. Object-level目标检测

    输出：bbox + class + score

    boxes ∈ RN×6
  3. Pixel-level语义分割

    输出：class per pixel

    mask ∈ {0…C-1}H×W
  4. Instance-level实例分割

    输出：mask + bbox + instance id

    {bbox,class,mask,id}N
02

任务谱系说明

Process Notes

01
预测单位

类别、目标、像素、实例对应不同监督粒度，输出数量逐步增加。

02
空间结构

分类无显式位置；检测使用 bbox；分割使用与图像对齐的 mask。

03
评价协议

Accuracy、IoU、AP、mIoU 和 Mask AP 针对不同输出结构。

输出结构对照表 SHAPE & METRIC
Classification图像级
p(y | image) ∈ RC

Metric: Top-1 / Accuracy

Detection目标级
boxes ∈ RN×6

Metric: IoU / AP / mAP

Semantic Segmentation像素级
mask ∈ {0…C-1}H×W

Metric: Pixel Acc / mIoU

Instance Segmentation实例级
instances = {bbox,class,mask,id}N

Metric: Mask AP
