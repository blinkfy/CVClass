Task Pipeline

Input Image → Person Region → Keypoints → Skeleton → Pose Vector

01 Input Image

输入可以是整张图像，也可以是检测后的人体 crop。

02 Person Region

人体框限定关键点预测的空间范围。

03 Keypoints

输出关节点坐标、置信度与可见性。

04 Skeleton

按骨架模板连接肩、肘、腕、髋、膝、踝等结构。

05 Pose Vector

把关键点坐标合并为可供动作识别使用的结构化向量。

Technical Summary

任务边界

输入
人体图像、人体框或裁剪区域。
输出
关键点坐标、score、visible、骨架连接。
数据集
LSP / FLIC / COCO Keypoints。
指标
PCK、OKS、Keypoint AP。
与分类、检测、分割的区别

姿态估计不只判断“有人”或“人在哪里”，而是输出人体内部的结构点和几何关系。
