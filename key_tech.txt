计算机视觉课程实验系统关键技术说明

1. Flask Web 系统
本系统使用 Python Flask 提供 Web 服务，负责主页路由、图片上传接口、参数接收、异常处理和图像处理函数调用。

2. 原生 HTML/CSS/JavaScript 前端交互
前端不使用 React、Vue 等大型框架，使用原生 HTML、CSS、JavaScript 实现页面分页、文件上传、参数控制、结果展示、处理记录和卷积逐步演示。

3. NumPy 图像处理
第一节图像处理实验使用 NumPy 对图片数组进行手动计算，包括灰度化、RGB 通道分离、二值化、颜色反转、翻转、旋转和灰度直方图均衡化。项目不使用 OpenCV/cv2。

4. 矩阵卷积计算
第二节卷积可视化实验使用 JavaScript 实现矩阵卷积。输入矩阵和卷积核以二维数组表示，输入随机值范围为 0-255，卷积输出通过逐项乘加得到。

5. padding、stride、dilation
系统支持 padding 补 0、stride 步长移动和 dilation 空洞采样，并显示输出尺寸公式：
effectiveK = dilation × (K - 1) + 1
outH = floor((H + 2P - effectiveK) / S) + 1
outW = floor((W + 2P - effectiveK) / S) + 1

6. 多卷积核
系统支持 1 到 4 个卷积核。每个卷积核作用于相同输入矩阵，并生成一个独立 Feature Map，用于展示“一个卷积核对应一个输出特征图”的关系。

7. 多通道卷积
系统支持 1 通道和 3 通道输入。多通道卷积中，每个输入通道都有对应的卷积核权重，各通道分别计算 partial sum，最终相加得到一个输出值。

8. 1×1 卷积
1×1 卷积模式会自动将卷积核大小设为 1，重点展示同一空间位置上的多通道融合。它不扩大空间邻域，常用于通道融合、压缩或升维。

9. 空洞卷积
空洞卷积使用 dilation 参数扩大采样间隔。dilation 控件只在空洞卷积模式下显示和启用。系统会高亮实际采样点，并用淡色虚线标出被跳过的位置，帮助理解空洞卷积如何在不增加参数量的情况下扩大感受野。

10. 蛇形卷积
系统实现教学版“蛇形路径采样卷积”。在 3×3 或 5×5 局部窗口内，只采样弯曲路径上的点，非路径区域不参与乘加，用于展示非规则路径上的特征提取。

11. 可视化高亮和逐步演示
系统支持单步计算、自动播放和重置演示。每一步都会高亮输入窗口、当前采样点、卷积核、当前输出位置，并显示乘加公式和多通道 partial sum。
