当前概念解释

平行双目系统 OL / OR 光轴平行，基线 b 已知 左右相机基线 b 已知，校正后同名点位于同一行。
水平极线约束 yL = yR 二维匹配搜索被压缩成沿水平扫描线的一维搜索。
当前观测 P(X,Y,Z) -> xL=--, xR=--, 同一水平行
同一个三维点会在左右图像中形成一对同名投影点。
校正后双目图像对应点落在同一水平行，匹配搜索更稳定。
基线越大同一深度下 xL 与 xR 的水平位置差更明显。
