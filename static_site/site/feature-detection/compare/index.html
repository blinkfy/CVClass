当前选中算法说明

类别：尺度不变特征

特点：具备尺度和旋转鲁棒性，关键点信息丰富。

优点：匹配稳定，适合跨尺度、旋转和光照变化场景。

缺点：计算量较大，流程比角点检测更复杂。

适用：图像匹配、目标识别、图像拼接。
