概念解释：IoU 交并比

交并比 (Intersection over Union) 衡量预测框与真实框的重合度，是 NMS 和精度评估的核心指标。

框 A
框 B
A ∩ B
重叠面积（交集） 总覆盖面积（并集） = IoU 分数
概念解释：BBox 偏移修正

边界框回归 (BBox Regression) 通过预测平移与缩放参数微调候选框位置：

x' = xp + dx · wp 横向平移
y' = yp + dy · hp 纵向平移
w' = wp · edw 宽度放缩
h' = hp · edh 高度放缩
