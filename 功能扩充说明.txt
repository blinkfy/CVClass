《计算机视觉》实验三·自行扩充功能更新说明

一、更新目的

本次实验的基本要求是展现一个卷积神经网络的可视化过程，并重点展示前向传播、反向传播、梯度计算和参数更新过程。在完成基础要求的基础上，我进一步扩充了系统功能，使页面不仅能够展示 CNN 的层级结构，还能从“计算过程、梯度回传、参数更新、训练轨迹”多个角度解释模型如何完成学习。

扩充功能主要围绕以下目标展开：

1. 让 CNN 的前向计算过程更加直观；
2. 让反向传播中的梯度计算过程可视化；
3. 让卷积核、全连接权重、bias 等可学习参数能够被观察；
4. 让参数更新与 loss 下降之间建立联系；
5. 形成适合课程录屏展示的交互式实验页面。

二、扩充功能总览

本次在基础 CNN 可视化页面之外，主要增加了以下扩展功能：

1. 网络结构与特征流可视化；
2. 层级计算探针 Computation Probe；
3. 前向传播与反向传播的局部计算链展示；
4. 卷积核、FC 权重和 bias 的参数可视化；
5. 反向传播梯度热力回放；
6. 参数更新过程可视化；
7. 3D 正反向传播整体流程演示；
8. Loss Landscape 训练轨迹可视化；
9. 多学习率梯度下降轨迹对比；
10. 手写数字识别模型联动展示。

三、CNN 网络结构与特征流可视化

系统新增 CNN 结构总览页面，将手写数字 CNN 的输入层、卷积层、激活层、池化层、展平层、全连接层和 Softmax 输出层按照从左到右的方式展开。

页面能够展示 28×28 手写数字输入、Conv、ReLU、MaxPool、Flatten、FC、Softmax 等层级结构，各层 feature map 热力图、层间连接关系、Softmax 输出概率条，以及当前选中层的输入尺寸、输出尺寸和核心公式。

该功能用于帮助观察 CNN 如何从原始像素逐步提取笔画、局部结构和分类特征。

四、Computation Probe 层级计算探针

为了避免只展示网络结构而缺少计算细节，系统增加了 Computation Probe 机制。用户点击某一层、某个 feature map 或某条连接时，系统会展开该层的局部计算解释。

探针内容包括：当前层名称、输入尺寸、输出尺寸、当前代表性通道/位置/连接、核心公式、数值代入、计算链和本步结论。

该功能将复杂 CNN 中的大量计算缩减为一个代表性位置或代表性连接，使计算过程既可解释又不会造成页面信息过载。

五、前向传播局部计算链展示

在前向传播模式下，用户点击不同层时，系统会展示该层的前向计算过程。

1. 卷积层：展示 input patch、kernel、逐元素乘积、sum+bias 和输出 feature map 位置；
2. ReLU 层：展示 Z 输入经过 A=max(0,Z) 后，负值被截断为 0，正值保留；
3. MaxPool 层：展示 2×2 pooling region、最大值位置和池化输出；
4. Flatten 层：展示 feature volume 如何 reshape 成一维向量；
5. FC 层：展示输入节点、权重连接、bias 和输出 logit 的加权求和；
6. Softmax 层：展示 logits 经过指数归一化得到 0 到 9 的分类概率。

该功能使前向传播不只是“从左到右流动”，而是能够看到每一层实际执行的数学运算。

六、反向传播梯度计算链展示

在反向传播模式下，系统能够展示各层梯度如何计算和回传。

1. Softmax + Cross Entropy：dlogits = probs - onehot(label)
2. FC 层：dW[i,j] = input[i] × dy[j]，db[j] = dy[j]，dinput = dy · W^T
3. Flatten 层：dPool = reshape(dflat)
4. MaxPool 层：dA[argmax] = dP，其余位置为 0
5. ReLU 层：mask = 1(Z > 0)，dZ = dA × mask
6. Conv 层：dK += input patch × dZ，db += dZ，dX_patch += kernel × dZ

通过这些计算链，系统能够明确展示“反向传播不是简单把箭头倒过来”，而是每一层都有对应的梯度规则。

七、卷积核与全连接参数可视化

为了突出 CNN 中“可学习参数”的作用，系统扩展了参数可视化功能。

卷积层中展示 kernel bank、代表性 3×3 卷积核、bias、dK 梯度、dK contribution 和更新前后的 kernel 对比。

全连接层中展示权重矩阵局部热力图、代表性连接 W[i,j]、dW[i,j] 梯度、bias 梯度和更新前后的权重变化。

颜色语义为：蓝色表示前向激活或旧参数，橙色表示反向传播梯度，绿色表示参数更新后的新值，灰色表示无梯度或被阻断位置。

该功能使卷积核和全连接权重不再只是抽象变量，而是可以在页面中直接观察。

八、反向传播梯度热力回放

系统在 Explainer 页面中增加了“梯度热力回放”功能。用户可以点击 Softmax/output 层中的任意类别，将该类别设置为当前样本的正确标签 targetLabel。

点击后系统会提示“已将类别 X 设为正确标签，开始回放从 Softmax 到输入端的反向传播梯度”，并根据 targetLabel 计算：

dlogits = probs - onehot(targetLabel)

随后系统从右向左逐层播放梯度回传动画：

Softmax → FC/logits → Flatten → Pool → ReLU → Conv → Input → Parameter Update

回放过程中，橙色热力表示梯度强度，线条越粗、颜色越深，表示梯度绝对值越大；灰色表示梯度接近 0 或被阻断；绿色表示最终参数更新。该功能能够直观展示梯度从输出层向输入层传播的过程。

九、3D 正反向传播整体流程演示

系统新增 3D CNN 可视化页面，用于展示整个 CNN 的正向传播和反向传播流程。

该页面包含 3D CNN Stage、手写数字输入、Forward/Backward 模式切换、播放/暂停、重置视角、层级可见性控制、显示连接线/显示标签/显示热力图等选项、底部 Step Timeline 和 Computation Probe Overlay。

3D 页面重点展示整体传播方向：

1. 前向传播：输入 → 卷积 → 激活 → 池化 → 全连接 → 输出；
2. 反向传播：Softmax 梯度 → FC 梯度 → Pool 梯度路由 → ReLU mask → Conv 梯度分解 → 参数更新。

该页面与 Explainer 页形成互补：Explainer 页强调局部计算细节，3D 页强调整体传播过程。

十、Loss Landscape 训练轨迹可视化

为了进一步展示梯度下降如何影响模型训练，系统增加了 Loss Landscape 面板。训练脚本会在训练过程中保存参数快照、loss、accuracy、梯度范数和更新范数等信息，并在前端绘制训练轨迹。

面板包含：

1. 当前 step、loss、accuracy、learning rate、grad norm、update norm；
2. train loss / val loss 曲线；
3. PCA 参数轨迹 3D 图；
4. FC2 最后一层二维 loss surface。

其中，PCA 参数轨迹将训练过程中的参数快照投影到二维主成分空间，并以 loss 作为高度，展示参数如何在低维投影空间中移动。FC2 loss surface 固定 CNN 其他层，只改变最后一层 FC 参数，在两个 PCA 方向上扫描得到二维损失切片。

该功能用于说明：反向传播计算梯度后，参数会沿着降低 loss 的方向更新。

十一、多学习率梯度下降轨迹对比

在 Loss Landscape 面板基础上，系统进一步扩展了学习率对比功能。训练脚本会分别使用多个 learning rate 训练模型，例如 lr=0.001、lr=0.01、lr=0.05、lr=0.1。

为了保证对比公平，不同学习率使用相同随机种子初始化，并将所有学习率的 FC2 参数快照投影到同一个 PCA 坐标系中。

前端能够展示不同学习率下的 loss 曲线、PCA 参数轨迹、当前选中学习率的高亮轨迹、其他学习率轨迹的半透明对比，以及发散或震荡轨迹的提示。

该功能用于说明学习率对梯度下降路径的影响：学习率过小会收敛较慢，学习率合适时 loss 稳定下降，学习率过大时可能产生震荡甚至发散。

十二、手写数字识别联动展示

系统继续复用已有手写数字识别功能，使用户可以直接在页面中书写数字，并观察 CNN 对当前输入的预测结果。

联动内容包括：Canvas 手写输入、28×28 预处理结果、当前预测类别、Softmax 概率分布、Explainer 中的 feature map 响应、3D CNN 页面中的输入张量，以及反向传播回放中的 targetLabel 设置。

该功能使模型输入、前向分类、反向梯度和参数更新形成完整闭环。

十四、扩充功能总结

本次自行扩充功能从单纯 CNN 结构展示扩展到了完整的“计算—梯度—更新—训练轨迹”可视化链路。系统不仅能展示卷积层、池化层和激活函数的前向传播，还能展示 Softmax 梯度、FC 梯度、MaxPool 梯度路由、ReLU mask 阻断、Conv dK/db/dX 梯度分解和参数更新过程。

通过 Explainer 页面，用户可以查看各层局部计算细节；通过 3D 页面，用户可以观察整体正反向传播流程；通过 Loss Landscape 面板，用户可以进一步理解不同学习率下梯度下降轨迹的差异。这些扩展功能使系统不仅满足基础作业要求，也更完整地展示了 CNN 从前向推理到反向学习的全过程。
